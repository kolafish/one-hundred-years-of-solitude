# 《马孔多的羊皮纸》五幕战役与视觉重构设计方案（Plan）

> 本文档为「马孔多的羊皮纸」回合制机关解谜游戏的整体升级蓝图，面向 **GitHub Pages 网页版**（`macondo-puzzle/`）与 **微信小程序端**（`miniprogram/pages/game/`）双端同步演进，核心引擎与图标资产继续保持共享。

---

## 一、设计目标与核心原则

1. **双端共用核心资产**：关卡数据、回合逻辑、因果状态机、Canvas 2D 棋盘绘制与矢量图标系统全部沉淀在 `miniprogram/game/`，网页与小程序仅做轻量壳层与存储适配。
2. **打破单关孤岛**：从单张 `10×8` 固定关卡扩展为 **5 幕连续战役**，通过「人物图鉴解锁 + 战前先祖出战配置 + 跨关卡因果开关 + 羊皮纸残页收集」形成真正的前后钩连。
3. **统一铜版羊皮纸视觉**：彻底移除棋盘与 UI 中的系统原生 Emoji，全部升级为手绘线条感、高辨识度的铜版羊皮纸矢量图形与自定义徽章。

## 二、视觉与图标重设计规范（Phase 1，已优先落地）

### 1. 配色与材质体系
- **羊皮纸基底**：`#f4ebd9` / `#efe3ca` / `#e7d7b9`，辅以纸纹颗粒与暗角晕影。
- **焦茶线稿**：`#2c1e16`（主轮廓）与 `#5c4332`（内结构纹理）。
- **黄铜与金辉**：`#c59b27` / `#d97706` / `#f5c96b`（机关、护盾、羊皮纸光晕与黄蝴蝶）。
- **朱砂与烈焰**：`#9e2a2b` / `#e63946`（烈日聚焦光束、火漆印、危险警示）。
- **马孔多河靛蓝**：`#325d78` / `#437897`（流水渐变与动态波纹）。

### 2. 双端共享矢量图标方案（`miniprogram/game/icons.js`）
- **棋盘内部（Canvas 2D）**：全部使用纯 Canvas 路径函数绘制（兼容所有浏览器及微信基础库，不依赖跨平台兼容性不稳定的特性）：
  - **主角**：焦黑铜框徽记 + 手提黄铜风灯（灯芯微光呼吸动效）；激活护盾时外环旋转虚线并点缀「小金鱼」护符节点。
  - **家族人物棋子**：浮雕圆章底座 + 专属单色线稿纹章（磁铁砝码、小金鱼勋章、左轮准星、钥匙串、星盘、黑纱、纸牌、白床单金蝶、古梵文卷轴）。
  - **火药桶**：木板弧线酒桶造型 + 双铁箍铆钉 + 顶部弯曲引信与动态火星。
  - **羊皮纸密室**：双轴卷轴 + 朱砂火漆印 + 扇动双翼的金色黄蝴蝶。
  - **地形升级**：斜切面砖石墙、岸边水纹河流、带铆钉木桥、渗出微光的裂纹石墙、黄铜凸透镜发射台。
- **UI 面板图标**：统一生成带明确 `viewBox` 的矢量 SVG；网页端渲染为内联 `<svg>`，微信小程序端渲染为 URL 安全编码的 `data:image/svg+xml` `<image>`，实现双端像素级统一。

## 三、关卡之间的三大联动机制

### 1. 人物解锁与「先祖同行槽位」（Loadout System）
- 玩家每通关一幕，对应核心人物永久加入**【布恩迪亚家族图鉴】**。
- **同行槽位规则**：
  - 第 1 幕：0 个战前槽位（教学引导，在地图内依次结识 3 位先祖）。
  - 第 2～3 幕：开放 **1～2 个** 战前同行槽位，玩家可从已解锁人物中自由挑选携带开局（同时本关地图中仍可遇见新登场人物）。
  - 第 4 幕：开放 **2 个** 战前同行槽位。
  - 第 5 幕：开放 **3 个** 战前同行槽位，集结家族之力迎战终局。
- **重玩价值**：后期解锁强力或特殊地形能力（如乌尔苏拉搭桥、蕾梅黛丝跨河飞升）后，可以**重玩早期关卡**，刷新更少回合数（S 级评价）或拿到首次错过的高难度残页。

### 2. 羊皮纸因果开关（Causal World Flags）
前几幕中的**支线动作或路径抉择**会写入持久化的 `worldFlags`，直接改变后续关卡的地图布局或机关状态：

| 因果标记 | 触发来源 | 对后续关卡的具体影响 |
| :--- | :--- | :--- |
| `ICE_PRESERVED` | **第 1 幕**：在通关前顺路拾取并带出角落的「冷冽冰块」 | **第 2 幕**广场中央炽热焦土被冰块冷却，打开一条省 4 步的近道 |
| `BRIDGE_REPAIRED` | **第 2 幕**：选择修复南岸木桥而非触发塌陷绕行 | **第 4 幕**大雨涨潮时，该处保留一座高架坚固木桥作为关键落脚点 |
| `ARCHIVE_INTACT` | **第 3 幕**：未炸毁档案室墙体而通过踩踏板开门通关 | **第 5 幕**终局密室外围的秘密侧门自动开启，跳过一道烈日光束封锁 |
| `GOLD_FISH_FORGED` | **第 3 幕**：集齐 2 枚熔炉金屑交给上校锻造小金鱼 | **第 4 / 5 幕**若携带奥雷里亚诺上校，其【宿命护盾】额外增加 1 次充能 |

### 3. 梅尔基亚德斯残页（Relic Collection）
- 第 1～4 幕每关隐藏 **1 枚「羊皮纸残页」**，通常放置在风险区域或需要技能配合的支线尽头。
- 集齐 4 枚残页后进入第 5 幕并抵达终点，将触发**真结局「百年真相完全破译」**；否则触发**普通结局「飓风掠境前的仓促撤离」**。

## 五、五幕详细关卡设计蓝图

### 第一幕：吉卜赛人的烈日与磁铁（`10×8`）
- **叙事定位**：教学幕。复刻并微调现有经典第一关。
- **地图要素**：外河与内河两道水域、1 座烈日发射器、1 个火药桶、1 处裂纹石墙。
- **核心解法**：何塞（投掷）→ 上校（护盾穿光束）→ 丽贝卡（狙击）→ 将桶抛至内河木桥并隔河引爆。
- **新增联动改造**：
  - 在左下/左上死角增设**「冷冽冰块」**（可选拾取，需要额外绕行 3 步或利用投掷调配），拾取后写入 `ICE_PRESERVED`；
  - 河对岸隐蔽角落增设第 1 枚**「羊皮纸残页」**（首次可利用多余投掷次数或后续带着蕾梅黛丝/乌尔苏拉回来拿）。
- **通关解锁**：`JOSE`、`AURELIANO`、`REBECA` 正式入驻图鉴。

### 第二幕：失眠症与镜面广场（`11×8`）
- **新增地形/机关**：
  - **旋转铜镜（`MIRROR_NE` / `MIRROR_NW`）**：将水平/垂直烈日光束 90° 折射；玩家靠近后可执行“拨转铜镜”动作（消耗 1 回合）。
  - **失眠迷雾（`FORGET_MIST`）**：踏入后玩家的主动技能暂时被“遗忘封印”2 回合，除非先经过广场上的「备忘字条格」或由乌尔苏拉同行解除。
- **跨关联动**：
  - 可带 1 位第 1 幕先祖开局；
  - 若 `ICE_PRESERVED` 为真，广场中段的高温炙烤地砖（不可直行）会化为凉爽石板，开放双路线。
  - 南侧存在“拆桥快速通道”与“修桥稳妥通道”，修桥后点亮 `BRIDGE_REPAIRED`。
- **通关解锁**：`URSULA`、`MELQUIADES`。

### 第三幕：十七次战争与金鱼工坊（`12×9`）
- **新增地形/机关**：
  - **压力踏板（`PLATE`）与铁栅门（`GATE`）**：需要将可移动火药桶、铜镜或重箱推/投至踏板上，铁门才保持开启。
  - **巡逻守卫（`GUARD`）**：沿固定折返路径每回合移动 1 格，面向前方 3 格投射红色警戒扇区；被射中时若有【宿命护盾】可豁免并打断警报，否则任务失败。
  - **可破坏档案墙 vs 绕行开关**：直接用火药桶炸开会摧毁档案，虽能快速过关但无法点亮 `ARCHIVE_INTACT`；若利用丽贝卡远程击打机关或阿玛兰妲黑纱遮蔽守卫视线，可无伤打开正门并保护档案。
- **跨关联动**：开放 2 个同行槽位；地图内可收集两块金屑触发 `GOLD_FISH_FORGED`。
- **通关解锁**：`AMARANTA`、`PILAR`。

### 第四幕：四年十一个月零两天的大雨（`12×9`）
- **新增地形/机关**：
  - **潮汐浅滩（`SHALLOWS`）**：以 2 回合为周期在「可通行浅滩（偶数回合）」与「不可跨越深水（奇数回合）」之间切换；系统会在即将涨潮的回合末尾用动态虚线水波提醒。
  - **激流漂移**：水边的火药桶/木箱在涨潮瞬间顺水流向指定方向漂移 1 格，玩家可利用激流把桶送到正常步行无法抵达的对岸！
- **跨关联动**：
  - 若第 2 幕点亮 `BRIDGE_REPAIRED`，中央关键浅滩直接变为永久木桥，大幅降低回合压力；
  - 携带【庇拉尔·特尔内拉】可随时反转潮汐节奏，携带【乌尔苏拉】可架设永久桥梁固定漂流物落点。
- **通关解锁**：`REMEDIOS`。

### 第五幕：飓风中的羊皮纸密室（`13×9`）
- **新增地形/机关**：
  - **飓风风圈（`HURRICANE_EDGE`）**：从第 15 回合起，棋盘最外圈开始逐层标记“飓风警示区”，第 18 回合起外圈变为不可踏入的废墟，营造终局紧迫感（支持随时 Undo 回退回合）。
  - **古梵文封印门（`RUNE_SEAL`）**：需先引导【奥雷里亚诺·巴比伦】同行并在封印前完成译码，再配合镜面折射光束击碎门前水晶与连锁引爆火药桶。
- **跨关联动**：
  - 开放 **3 个先祖同行槽位**；
  - 若 `ARCHIVE_INTACT` 为真，密室西侧秘道直接开启；
  - 结算时统计 1～5 幕累计获得的羊皮纸残页数，决定「百年真相完全破译（真结局）」或「飓风中逃离（标准结局）」。

## 六、引擎重构与存储架构设计

### 1. `miniprogram/game/macondo.js` 模块化拆分
- **`LEVELS` 数据表**：每关定义 `{ id, title, subtitle, cols, rows, slots, parTurns, terrain, npcs, barrels, boxes, mirrors, guards, plates, relics, causalHooks, hints }`。
- **通用引擎状态机**：
  - `resolveTurn()` 严格按照固定顺序执行，确保 Undo 快照完全确定性：
    1. 玩家移动 / 技能动作生效；
    2. 拾取 NPC / 残页 / 因果道具；
    3. 踏板与铁栅门状态重算；
    4. 巡逻守卫按确定性路径步进；
    5. 潮汐水位周期结算与激流物体漂移；
    6. 光束发射 + 镜面反射重算（使用 `visited` 集合防止反射死循环；光束命中火药桶触发连锁引爆）；
    7. 玩家受击判定（光束 / 守卫 / 溺水，优先消耗护盾）；
    8. 终点通关 & 存档写入。
- **Undo 快照栈**：对动态实体（`terrain`、`player`、`npcs`、`barrels`、`boxes`、`mirrors`、`guards`、`abilities`、`turn`、`mistTimers`、`tidePhase`、`localFlags`）进行深拷贝压栈。

### 2. 跨端持久化存储（`macondo_puzzle_progress_v1`）
在网页端使用 `window.localStorage`，在小程序端扩展 `miniprogram/utils/storage.js`（使用 `wx.getStorageSync` / `wx.setStorageSync`）：

```json
{
  "schemaVersion": 1,
  "unlockedLevels": [1, 2],
  "completedLevels": {
    "1": { "bestTurns": 16, "rank": "S", "relicCollected": true }
  },
  "unlockedCharacters": ["JOSE", "AURELIANO", "REBECA"],
  "worldFlags": {
    "ICE_PRESERVED": true,
    "BRIDGE_REPAIRED": false,
    "ARCHIVE_INTACT": false,
    "GOLD_FISH_FORGED": false
  },
  "lastSelectedLoadout": ["JOSE"]
}
```

### 3. 双端 UI 交互升级要点
- **网页端（`macondo-puzzle/`）**：
  - 顶部新增「五幕编年史导航条」（显示关卡解锁状态、残页星标与因果连线提示）；
  - 新增「家族图鉴与出战配置」抽屉/弹窗（展示 9 位人物铜版徽章、经典原著引语、主动/被动说明与槽位装配）；
  - 修改任何 Tailwind 类后，按注释命令重新生成 `macondo-puzzle/tailwind.css`。
- **微信小程序端（`miniprogram/pages/game/`）**：
  - `hit-grid` 改为根据引擎返回的当前关卡 `cols` / `rows` 动态生成，不再写死 `10×8`；
  - 棋盘 `board` 容器纵横比根据 `rows / cols` 动态计算（例如 `padding-bottom: {{boardRatio}}%`）；
  - 在 `pages/game/index.wxml` 顶部增加轻量关卡切换胶囊与「出战配置」半屏弹层。

## 七、分阶段落地与验证计划

1. **阶段 A（已完成/当前阶段）**：制定本设计文档 + 实现双端共享矢量图标系统（`miniprogram/game/icons.js`）+ 全面重绘棋盘 Canvas 地形/角色与双端 UI 图标。
2. **阶段 B（引擎多关卡重构）**：将 `macondo.js` 升级为数据驱动多关引擎，接入折射镜、踏板门、守卫、潮汐、先祖槽位与跨端持久化。
3. **阶段 C（五幕实装与双端界面）**：填充 1～5 幕地图数据与剧情日志，实装网页与小程序选关/图鉴/编队界面。
4. **阶段 D（自动化验证）**：编写 Node.js 无头通关测试脚本（直接 `require('./miniprogram/game/macondo.js')`），对 5 幕主线、残页支线、因果开关和 Undo 一致性进行全量自动化回归测试。
